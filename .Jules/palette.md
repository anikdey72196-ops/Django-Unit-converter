## 2024-05-24 - Required ARIA labels for visually grouped inputs without explicit labels
**Learning:** When using a clean, modern UI design where an input and its corresponding dropdown select are visually grouped together under a single label (e.g., "From" or "To" above a container), screen readers will not naturally associate the overarching text label with the dropdown select element. The visual layout implies association, but the DOM does not.
**Action:** When working with modern form designs that group elements (like value input + unit select) under a single visual heading, always explicitly add independent `aria-label` attributes to the select elements (e.g., `aria-label="Source unit"`) to ensure the interactive elements are fully accessible without compromising the visual aesthetic.
