## 2024-05-17 - Add ARIA Labels to Icon-Only Buttons and Grouped Select Elements
**Learning:** Icon-only buttons (like swap units, copy result, mobile menu toggle) and `<select>` dropdowns visually grouped with other inputs often lack explicit accessibility descriptors. Even if visually clear via context or an overall group label (like "From" or "To"), a screen reader might not correctly announce the individual interactable element's purpose without a direct `aria-label`.
**Action:** Always ensure any `<button>` containing only an SVG or icon has an explicit `aria-label` attribute. For form groups containing multiple interactable fields under a single visual label (e.g., an `<input>` for the number and a `<select>` for the unit under the "From" label), ensure each individual control is directly accessible, utilizing `aria-label` for inner controls like the `<select>` unit dropdown.
