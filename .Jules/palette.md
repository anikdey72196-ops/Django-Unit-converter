## 2026-06-17 - Add ARIA Labels and Focus Rings
**Learning:** Found an accessibility issue pattern specific to this app's components where multiple icon-only interactive elements (mobile menu toggle, swap unit button, copy result button) lack proper accessible naming (`aria-label`) and explicit keyboard focus indicators (`focus-visible`). Additionally, the `select` dropdowns lack associated labels, which is detrimental to screen readers.
**Action:** When adding new interactive components or forms in this codebase in the future, always remember to add `aria-label` for icon-only buttons or context-less inputs, and explicitly declare `focus-visible:ring-2 focus-visible:outline-none` using the Tailwind utility classes to ensure adequate keyboard accessibility out of the box.
