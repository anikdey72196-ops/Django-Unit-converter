## 2026-07-09 - ARIA Labels for Grouped Select Elements
**Learning:** when grouping interactive elements (like a value input and a unit select dropdown) under a single visual label, always provide individual aria-label attributes to the inner elements (e.g., the select dropdown) to ensure they are fully accessible to screen readers.
**Action:** Apply targeted `aria-label` attributes to inner elements of compound fields, like select dropdowns within a group, even when there's an overarching visual label.
