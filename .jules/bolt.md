## 2026-03-05 - Event Delegation & DOM Reconciliation Avoidance
**Learning:** In highly interactive single-page vanilla JS applications, rapidly clicking history or popular items often redundantly re-initializes identical DOM states (like `<option>` dropdowns) and duplicates core calculations if not properly debounced or short-circuited. Rebuilding UI via multiple `createElement` in a loop also consumes more memory over time than event delegation.
**Action:** Use an early-return check to short-circuit state recreation when clicking links matching the current state, provide optional bypass flags (e.g. `preventCalculate`) to avoid duplicate firing of heavy functions, and replace loop-based listeners with single container-level event delegation (e.g., `addEventListener('click')` with `.closest()`).
